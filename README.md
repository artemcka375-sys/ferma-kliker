# Ферма Кликер

Десктопная кликалка: дои корову Саню, лови кефир, корми дронов беконом и слушай, как Илюша Говрюша делает вид, что он консультант.

Играть можно в опубликованном приложении. Окно, меню «Пуск», горячие клавиши и файл сохранения — как у программы, только открывается в браузере.

## Управление

- Клик или пробел — доить Саню
- M — звук
- Esc — закрыть окно
- Пуск — справка, отпуск, новая ферма, файл сохранения

## Что внутри

- Сила клика, доярки, Лёва, Денис, менеджер, автокликер
- Кефир (0,23%, Илюша добавляет 0,5%) — +50% на 30 секунд
- Бекон (+0,05% к дронам за уровень) — дроны дают +5 000/с на 120 секунд
- Комбо, криты бабки Зины, трактор Васи, рация, алтарь ряженки, Клава
- Комбо 10 / 25 / 50 / 100 / 200 орёт на весь экран. С 50-го Саня в ярости: клики x2
- Коза-адвокат Галя, самовар дяди Коли, поющий холодильник
- Рабочий стол: Мой бидон, Корзина, save.json, Бекон.zip
- Отпуск (престиж): сено навсегда даёт +10% ко всему молоку
- Оффлайн-дойка, пока вкладка закрыта (до 4 часов, вполсилы)
